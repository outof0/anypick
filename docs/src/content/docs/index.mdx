Hotplug owns the boring half of using more than one AI provider: auth
snapshots, local proxies, protocol translation, and client configuration. You
pick a client and a source; it does the rest.

Nearly all of it happens in the terminal UI — run `hotplug` with no arguments.
The subcommands documented here mirror it one-for-one, for scripts and CI.
