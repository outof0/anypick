AnyPick answers one question for **Claude Code** and **Codex**: which login
should power this app right now? You pick on the **Apps** screen; AnyPick
handles auth snapshots, local proxies, and client config.

Run `anypick` with no arguments. The subcommands mirror the same flows for
scripts and CI.
