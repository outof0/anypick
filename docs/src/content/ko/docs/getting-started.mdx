AnyPick은 일상적인 질문 하나에 답합니다.

> **Claude Code 또는 Codex는 지금 어떤 로그인을 사용해야 합니까?**

귀하는 이미 제공자 비용을 지불하고 있습니다. 이미 코딩 도구를 사용하고 있습니다. AnyPick은 해당 로그인의 스냅샷을 찍고 도구가 다른 프로토콜을 말할 때 로컬 변환기를 시작하고 클라이언트 구성을 작성하므로 파일을 직접 편집하는 대신 **Apps**에서 한 번만 선택하면 됩니다.

## 릴리스 설치

해당 플랫폼의 패키지 관리자를 사용하여 최신 [GitHub 릴리스](https://github.com/outof0/anypick/releases/latest)에서 CLI를 설치합니다.

```bash
# macOS
brew install outof0/tap/anypick

# Linux, or any OS with Node 18+ (downloads the matching native CLI on first run)
npm install -g anypick
```

```powershell
# Windows
scoop bucket add outof0 https://github.com/outof0/scoop-bucket
scoop install anypick
```

데스크톱 앱(`.dmg`, `.deb`, `.rpm`, AppImage, `.msi`, `.exe`) 및 체크섬 목록의 CLI 타르볼이 모든 앱에 연결됩니다. [출시](https://github.com/outof0/anypick/releases/latest). `anypick --version`로 설치를 확인한 다음 `anypick doctor`를 실행하세요.

## 앱 열기

기본 macOS 대상은 일반 기본 창을 자동으로 엽니다. 메뉴 표시줄 빠른 패널은 동일한 앱의 일부이며 기본 창이 닫혀도 계속 사용할 수 있습니다.

터미널 워크플로의 경우:

```bash
anypick tui
```

**앱**에 도착합니다:

```
 anypick / apps

  Routes for Claude Code and Codex
 › Claude        not connected                     ○ not set
   Codex         not connected                     ○ not set
 ────────────────────────────────────────────────────────────────────────
 Connect Claude
 enter to build a route
 enter connect app a accounts g gateways p proxies d diagnose
```

**Claude Code**, **Codex**, **OpenCode**, **ZCode**, **`dsh`**, **`commandcode`**, **`pi`** 및 **`omp`**만 여기에 표시됩니다. 거의 모든 저장된 소스를 가리킬 수 있습니다. 다른 도구는 계정에서 자체 로그인을 전환합니다.

비전문가도 UI를 안전하게 만드는 세 가지 습관:

- **규칙 아래의 줄은 <kbd>enter</kbd>가 수행할 작업입니다.** 먼저 읽어보세요.
- **바닥글이 전체 키맵입니다.** 숨겨진 메뉴가 없습니다.
- **미리보기에서 알려줄 때까지 아무것도 저장되지 않습니다.** 언제든지 <kbd>esc</kbd>로 돌아갈 수 있습니다.

아래 명령 예시는 AnyPick의 CLI 문법을 보여줍니다. GitHub 릴리스의 체크섬 목록 아카이브에서 또는 `npm install --global anypick`(노드 18+, 처음 실행 시 일치하는 기본 CLI 다운로드)를 사용하여 씬 npm 실행기를 통해 CLI를 설치합니다. `make run ARGS="…"`를 사용하여 이 결제에서 동일한 인수를 실행할 수도 있습니다. 예를 들어 `make run ARGS="list accounts"`(또는 `make build`로 한 번 빌드하고 `./src/go/bin/anypick-dev …`를 직접 실행)입니다.

소스 전체 둘러보기 → 모델 → 미리보기: [터미널 UI · 앱](/ko/docs/guides/terminal-ui).

## 로그인을 한 번만 저장하세요.

AnyPick은 공급자 소유의 브라우저 로그인을 시작할 수 있습니다. 공급자의 OAuth 흐름 자체를 구현하거나 모방하지 않습니다.

UI에서: <kbd>a</kbd> **계정** → <kbd>a</kbd> **추가**. 또는:

<Steps>
<Step title="로그인 추가">
```bash
anypick add account codex --new --name personal
# opens Codex browser Auth and saves the result

# If Codex is already signed in, snapshot it instead:
anypick add account codex --current --name personal
```
</Step>
<Step title="나열된 것을 확인하세요">
```bash
anypick list accounts
```
</Step>
</Steps>

`provider/name` 쌍(예: `codex/personal` 또는 `grok/work`)은 앱에 연결할 **소스**입니다.

<Aside type="tip" title="동일한 제공업체에 두 번째 로그인">
`anypick add account codex --new --name work`는 현재 자격 증명을 숨기고, 공급자의 브라우저 인증을 열고, 결과를 저장하고, 첫 번째 계정을 저장된 상태로 유지합니다. 공식 인증이 선호됩니다. 공급자가 선언한 커뮤니티 방법은 계속 선택 가능합니다.
</Aside>

## 앱 연결(Apps UI)

**Apps**로 돌아갑니다(`anypick / apps`가 나타날 때까지 <kbd>esc</kbd>를 누르세요).

1.  **Claude** 또는 **Codex**를 강조표시하세요.
2. <kbd>enter</kbd>를 누릅니다(**앱 연결**).
3. 출처 선택:
   - **기본 계정** — 앱과 동일한 브랜드(간단한 스위치).
   - **게이트웨이 및 프록시** — Grok, OpenRouter, Gemini 프록시, 풀, …
   - **저장된 설정** — 이전에 저장한 사전 설정입니다.
4. 요청 시 모델을 선택하세요(Claude는 기본값/소네트/오푸스/하이쿠를 설정할 수 있음).
5.  **미리보기**를 읽어보세요. 무엇이 작성되고 어떤 프록시가 시작되는지 살펴보세요.
6. <kbd>enter</kbd>를 눌러 활성화하세요.

앱으로 돌아가면 행에 `source · model`와 함께 **● 준비**가 표시되어야 합니다.

일상적으로 사용하기 위한 전체 제품입니다. 평소대로 코딩 도구를 엽니다.

## 명령과 동일한 단계(선택 사항)

스크립트와 CI는 UI 없이 동일한 작업을 사용합니다.

```bash
anypick use codex --with codex/personal
anypick run codex
```

교차 공급자 예 - Grok 계정의 Claude(프록시가 자동으로 시작됨):

```bash
anypick add account grok --current --name work
anypick use claude --with grok/work
anypick run claude
```

로그인 대신 API 키 — **게이트웨이**를 등록한 다음 앱에서 선택하거나 `--with`에 전달하세요.

```bash
anypick add gateway openrouter-work \
  --provider openrouter \
  --endpoint https://openrouter.ai/api/v1 \
  --api-key "$OPENROUTER_API_KEY" \
  --model anthropic/claude-sonnet-4

anypick use claude --with openrouter-work
```

## 설정 후: 앱 또는 터미널

macOS에서는 [기본 앱 및 메뉴 모음](/ko/docs/guides/tray)이 앱 우선 일일 화면입니다. 관리에는 전체 창을 사용하고 경로 및 서비스 작업에는 메뉴 표시줄 빠른 패널을 사용하세요. 기본 창을 닫으면 앱이 계속 실행됩니다. 명시적 **Quit AnyPick**은 번들 서비스를 중지하고 종료합니다.

터미널 UI는 별도의 소스 개발 화면으로 유지됩니다. 별도로 출시된 네이티브 앱을 소유하거나 중지하지 않습니다.

<Aside type="note" title="TTY 없음, UI 없음">
파이프 또는 비대화형 실행은 절대 앱을 열지 않습니다. 스크립트의 `anypick`는 도움말을 인쇄하고 종료하므로 키를 기다리는 동안 아무 것도 중단되지 않습니다.
</Aside>
