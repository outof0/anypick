title: '使用量とコスト'
description: 'ローカルのプロキシ、プール、Proxy Hub が処理したトークン数を、モデル・アカウント・プロバイダー・日ごとに、日付付きの費用見積もりとともに確認します。'
---

実行中のプロキシ、プール、Proxy Hub が処理したリクエストはすべて数えられます。ベンダーが使用したトークン数を報告し、AnyPick はその数値をこのコンピューターに 90 日間保存します。`anypick usage` はそれを集計し、見積もり価格を付けます。

数えるのは AnyPick を経由したトラフィックだけです。自分のログインでベンダーと直接通信しているクライアントは見えません。

## 確認する

```bash
anypick usage                     # 直近 7 日、モデル別
anypick usage --by account        # どの保存済みアカウントが何を処理したか
anypick usage --by day --since 30d
anypick usage --json              # スクリプト用
```

`--since` には日数（`7d`）、期間（`24h`）、ローカルの日付（`2026-10-01`）を指定できます。`--by` は `model`、`account`、`provider`、`day` でまとめます。

LM Studio アカウントが 1 つあるサンドボックスでの出力:

```text
Usage since 2026-10-20 21:41, by account
                                      requests        input       output       cached     est. USD
lmstudio/stub                                2            6            8            0       0.0000
total                                        2            6            8            0       0.0000

Estimated at API list prices as of 2026-10-06; not a bill. Subscription logins are not charged per token.
```

## 記録される内容

成功した応答ごとに、処理した日時、処理したプロバイダーとアカウント、モデル、そしてベンダーが報告した入力・出力・キャッシュのトークン数を記録します。リクエストや応答の内容、ヘッダー、キーは一切保存しません。プールやハブが別のアカウントへ回した拒否済みのリクエストは数えず、最終的に応答したアカウントを数えます。

トークン数を含まない応答もあります。よくあるのは、`stream_options.include_usage` を付けずに送られた OpenAI 形式のストリームです。そうしたリクエストも数えられ、概要にはトークン数がなかった件数が表示されます。

## 見積もり

費用列は、価格を取得した日付付きの **API 定価による見積もり** です。請求書ではありません。

- サブスクリプションのログイン（Claude Pro、ChatGPT）はトークン単位で課金されません。その場合の数値は、同じトラフィックを API で使った場合の費用です。
- 同梱の価格表には Anthropic 自身の価格しかありません。表にないモデルは見積もりから除外され、何件が除外されたかが出力に表示されます。費用の後の `+` は、その行の一部のリクエストが除外されたことを示します。
- キャッシュ価格のないキャッシュトークンは入力価格で計算されるため、見積もりは高めになります。

価格を追加・修正するには、AnyPick のデータディレクトリ（既定は `~/.anypick`）に `pricing.json` を作成します。単位は 100 万トークンあたりの米ドルです。

```json
{
  "models": {
    "glm-4.7": { "input": 0.6, "output": 2.2 },
    "claude-opus-5-5": { "input": 4, "output": 20, "cacheRead": 0.2 }
  }
}
```

モデル ID は、`vendor/` という接頭辞があればそれを除いたうえで、完全一致するか、 `-` または `@` が続く接頭辞として一致します。そのため `claude-opus-5-20260101` は `claude-opus-5` の価格で計算されます。概要には、価格をあなたのファイルから取ったモデルが一覧表示されます。

## 別のプログラムから

[管理 API](/ja/docs/reference/management-api) は、同じ概要を `GET /v1/usage/history` で、同じ `since` と `by` オプション付きで提供します。デスクトップアプリはまだ使用履歴を表示しません。
