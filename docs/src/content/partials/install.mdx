<Aside type="caution" title="Release channels">
GitHub Releases are the canonical source for checksum-listed CLI archives for
macOS, Linux and Windows, plus the universal macOS `.dmg`/`.zip`, Linux desktop
installers, and Windows installers. The macOS app is not notarized; on first
launch, right-click `AnyPick.app` and choose **Open**, or choose **Open Anyway**
under **System Settings → Privacy & Security**. You can also run
`/usr/bin/xattr -dr com.apple.quarantine /Applications/AnyPick.app`. The thin npm
launcher (`npm install --global anypick`, Node 18+) downloads and verifies the
matching native CLI on first run. From 1.1.0 it replaces the old JavaScript
`anypick@1.0.x` on npm. Build from this repository when you are testing
unreleased changes.
</Aside>

Install the CLI or macOS app with Homebrew:

```bash
brew install outof0/tap/anypick
brew install --cask outof0/tap/anypick
```

Install the Windows CLI with Scoop:

```powershell
scoop bucket add outof0 https://github.com/outof0/scoop-bucket
scoop install anypick
```

For the native macOS source target (macOS 14+, Xcode, and Go required):

```bash
open src/macos/AnyPick.xcodeproj
```

Select the shared **AnyPick** scheme and Run. The build bundles the Go service
inside the app; it does not compile Swift or Go when the app launches.

For the current CLI and terminal UI source workflow (Go 1.26+ required):

```bash
make build
./src/go/bin/anypick-dev --help
./src/go/bin/anypick-dev tui
```

## Headless / Linux server

The CLI is a static Go binary: no GUI toolkit and no TTY required for non-interactive
commands. Without a terminal, `anypick tui` exits with `NO_TTY`; use `anypick list`,
`anypick use`, `anypick status`, `anypick serve`, or other CLI commands (`start` / `status` / `stop`).

Data lives under `~/.anypick` (override with `ANYPICK_HOME`). `anypick serve`
listens on `127.0.0.1` only — reach it from another host with an SSH tunnel.
Update by downloading a new release archive, `npm install --global anypick@latest`,
or `anypick update` (checks GitHub Releases).
