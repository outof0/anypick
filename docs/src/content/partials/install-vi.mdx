<Aside type="caution" title="Kênh phát hành">
Bản phát hành GitHub là nguồn chuẩn cho các kho lưu trữ CLI được liệt kê tổng kiểm tra dành cho macOS, Linux và Windows, cùng với macOS phổ biến `.dmg`/`.zip`, trình cài đặt máy tính để bàn Linux và trình cài đặt Windows. Ứng dụng macOS không được công chứng; trong lần khởi chạy đầu tiên, hãy nhấp chuột phải vào `AnyPick.app` và chọn **Mở** hoặc chọn **Vẫn mở** trong **Cài đặt hệ thống → Quyền riêng tư & Bảo mật**. Bạn cũng có thể chạy `/usr/bin/xattr -dr com.apple.quarantine /Applications/AnyPick.app`. Trình khởi chạy npm mỏng (`npm install --global anypick`, Node 18+) tải xuống và xác minh CLI gốc phù hợp trong lần chạy đầu tiên. Từ 1.1.0, nó thay thế JavaScript cũ `anypick@1.0.x` trên npm. Xây dựng từ kho lưu trữ này khi bạn đang thử nghiệm các thay đổi chưa được phát hành.
</Aside>

Cài đặt ứng dụng CLI hoặc macOS với Homebrew:

```bash
brew install outof0/tap/anypick
brew install --cask outof0/tap/anypick
```

Cài đặt Windows CLI bằng Scoop:

```powershell
scoop bucket add outof0 https://github.com/outof0/scoop-bucket
scoop install anypick
```

Đối với mục tiêu nguồn macOS gốc (yêu cầu macOS 14+, Xcode và Go):

```bash
open src/macos/AnyPick.xcodeproj
```

Chọn lược đồ **AnyPick** được chia sẻ và Chạy. Bản dựng gói dịch vụ Go bên trong ứng dụng; nó không biên dịch Swift hoặc Go khi ứng dụng khởi chạy.

Đối với quy trình làm việc nguồn giao diện người dùng thiết bị đầu cuối và CLI hiện tại (yêu cầu phiên bản Go 1.26+):

```bash
make build
./src/go/bin/anypick-dev --help
./src/go/bin/anypick-dev tui
```

## Máy chủ không đầu / Linux

CLI là một tệp nhị phân Go tĩnh: không có bộ công cụ GUI và không cần TTY cho các lệnh không tương tác. Nếu không có thiết bị đầu cuối, `anypick tui` sẽ thoát với `NO_TTY`; sử dụng `anypick list`, `anypick use`, `anypick status`, `anypick serve` hoặc các lệnh CLI khác (`start` / `status` / `stop`).

Dữ liệu tồn tại dưới `~/.anypick` (ghi đè bằng `ANYPICK_HOME`). `anypick serve` chỉ nghe trên `127.0.0.1` — truy cập nó từ một máy chủ khác bằng đường hầm SSH. Cập nhật bằng cách tải xuống bản lưu trữ phát hành mới, `npm install --global anypick@latest` hoặc `anypick update` (kiểm tra Bản phát hành GitHub).
