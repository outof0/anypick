AnyPick 为 **Claude Code** 和 **Codex** 解答一个问题：现在应该用哪个账号？你可以在原生 **Apps** 界面或终端界面中选择，AnyPick 会管理登录快照、本地代理和客户端配置。

从[最新 GitHub Release](https://github.com/outof0/anypick/releases/latest)下载带校验和的 CLI 压缩包，也可以运行 `npm install --global anypick` 安装轻量启动器（需要 Node 18+；首次运行时会下载并校验对应的原生 CLI）。GitHub Releases 还提供 macOS 应用、Linux 和 Windows 桌面安装包，以及各平台 CLI 压缩包。macOS 应用尚未进行公证；首次启动方式见[安装指南](/zh-cn/docs/getting-started)。从 1.1.0 起，npm 包已取代旧的 JavaScript `anypick@1.0.x`。先阅读[开始使用](/zh-cn/docs/getting-started)，了解 macOS 应用和 CLI/TUI 流程。子命令与界面执行相同的操作，也可用于脚本和 CI。
