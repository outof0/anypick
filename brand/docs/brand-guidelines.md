# AnyPick Brand Guidelines

## Brand core
**AnyPick** is an AI account, provider, and routing tool that helps developers pick the right route and keep coding.

### Brand idea
**Pick. Route. Go.**

### Tagline
**Pick any. Code on.**

### Brand attributes
- Fast
- Controlled
- Technical
- Modern
- Confident

## Naming and casing
- Always write the brand as **AnyPick**
- Domain, package, and technical slugs stay lowercase: `anypick`, `anypick.dev`
- Never write `Anypick` or `ANYPICK` as the primary brand form

## Logo system
Use `symbol-small.svg` for tiny sizes below 24px. Use clear space equal to one node diameter around the symbol.
Minimum sizes: full logo 24px high, wordmark 18px high, symbol 16px high.

## Tray and small-size guidance
Use `icons/tray/svg/tray-icon-template.svg` for native macOS template rendering and `icons/tray/svg/tray-icon-accent.svg` for colored contexts.
Do not auto-center or rebuild the tray icon.

## Color system
Primary: #7C3AED
Brand 400: #A78BFA
Brand 300: #C4B5FD
Brand 100: #EDE9FE

Neutrals: #0B0F19, #161B26, #2A3242, #475163, #98A2B3, #E6E8EE

Semantic: success #22C55E, warning #F59E0B, error #EF4444, info #3B82F6

## Typography
Display / headings: Space Grotesk
UI / body: Inter

## Product UI guidance
Use dark UI as the default expression. Use violet for primary actions and selected states only. Avoid turning the whole UI into a purple wash.
