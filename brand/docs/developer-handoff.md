## Asset usage map
- Marketing header: `logos/lockup-horizontal-primary.svg`
- Dark hero: `logos/lockup-horizontal-reverse.svg`
- Footer / narrow spaces: `logos/wordmark-primary.svg`
- App shell, buttons, avatars: `logos/symbol-primary.svg`
- Tray / tiny sizes: `logos/symbol-small.svg`

## Tray / menu bar
For a native macOS menu bar app, prefer `icons/tray/svg/tray-icon-template.svg` and mark it as a template image in the app bundle.
Do not use the full logo in the tray.
