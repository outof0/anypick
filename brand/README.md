# AnyPick Brand Kit — Option 3

Official brand direction chosen by the founder.

- **Brand name:** AnyPick
- **Tagline:** Pick any. Code on.
- **Concept:** Pick. Route. Go.
- **Primary URL:** anypick.dev

This package is developer-ready and includes logos, tray icons, app icons, color tokens, typography guidance, and handoff notes.

The wordmark is outlined from Space Grotesk, licensed under the SIL Open Font
License 1.1. No font binary is bundled with these assets or with AnyPick.

## Quick start
1. Read `docs/developer-handoff.md`
2. Use `tokens/design-tokens.json` as the source of truth
3. Use `logos/symbol-small.svg` for menu/tray sizes between 16–24px
4. Use `icons/svg/app-icon.svg` for app icon source and export from that file only
